---
title: "POST /execute"
description: "Execute Python in an isolated Docker sandbox."
---

Runs Python code in an isolated Docker sandbox with network isolation, memory limits, and a non-root user.

## Request body

```json
{
  "code": "print('hello from the sandbox')",
  "timeout": 30,
  "use_docker": true
}
```

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `code` | string | Yes | Python code to execute |
| `timeout` | integer | No | Execution timeout in seconds (default: 30) |
| `use_docker` | boolean | No | Use Docker sandbox isolation (default: true) |

## Response

```json
{
  "stdout": "hello from the sandbox\n",
  "stderr": "",
  "exit_code": 0,
  "duration_ms": 842
}
```

| Field | Type | Description |
|-------|------|-------------|
| `stdout` | string | Captured standard output |
| `stderr` | string | Captured standard error |
| `exit_code` | integer | Process exit code (0 = success) |
| `duration_ms` | integer | Execution time in milliseconds |

## Example

```bash
curl -X POST http://localhost:8009/execute \
  -H "Content-Type: application/json" \
  -d '{"code": "import sys; print(sys.version)"}'
```

## Sandbox limits

| Limit | Default |
|-------|---------|
| Memory | 128 MB (configurable via `SANDBOX_MEMORY_MB`) |
| Processes | 64 max |
| Network | Isolated — no outbound access |
| Filesystem | Read-only except `/tmp` |
| User | Non-root |
