title: "REST API"
description: "FusionAL gateway REST API reference."
---

The FusionAL gateway exposes a REST API alongside the MCP transport. Use it to execute code, manage the server registry, and trigger server generation programmatically.

**Base URL (local):** `http://localhost:8009`  
**Base URL (Docker):** `http://localhost:8089`

## Authentication

When API key auth is enabled, pass your key in every request:

```bash
curl -H "X-API-Key: your-api-key" http://localhost:8009/catalog
```

## Endpoints

| Endpoint | Method | Description |
|----------|--------|-------------|
| [`/health`](/api-reference/endpoint/health) | GET | Health check |
| [`/execute`](/api-reference/endpoint/execute) | POST | Execute Python in a sandbox |
| [`/generate`](/api-reference/endpoint/generate) | POST | Generate and launch an MCP server from a prompt |
| [`/register`](/api-reference/endpoint/register) | POST | Register an MCP server in the registry |
| [`/catalog`](/api-reference/endpoint/catalog) | GET | List all registered servers |

## Content type

All POST endpoints expect `Content-Type: application/json`.

## Error codes

| Code | Meaning |
|------|---------|
| 400 | Bad request — malformed JSON or missing required fields |
| 401 | Unauthorized — missing or invalid API key |
| 422 | Unprocessable entity — valid JSON but failed validation |
| 500 | Internal server error — sandbox failure or generation error |
