## What's included

| Server | Port | What it does |
|--------|------|-------------|
| Business Intelligence MCP | 8101 | Natural language → SQL (PostgreSQL, MySQL, SQLite) |
| API Integration Hub | 8102 | Slack, GitHub Issues, Stripe via natural language |
| Content Automation MCP | 8103 | Web scraping, RSS feeds, link extraction |
| Intelligence MCP | 8104 | Trending topics, business lead sourcing, repo intelligence |
| FusionAL Execution Engine | 8009 | Dynamic code execution + MCP server registry |

Each server exposes:
- A REST API for direct HTTP access
- An MCP Streamable HTTP endpoint at `/mcp` for any AI client
- A `/health` endpoint for monitoring

## Requirements

- Python 3.11+
- Docker Desktop
- Git

## Works on Windows, Linux, and macOS

All servers ship with cross-platform launch scripts. Windows hardening is built in.
