## What is FusionAL?

FusionAL is a self-hosted [Model Context Protocol](https://modelcontextprotocol.io) gateway that solves a specific enterprise problem: **token bloat from multi-server MCP setups**.

When Claude Desktop loads 6+ MCP servers, every conversation pays the context cost of all their schemas — whether or not you use them. FusionAL sits in front of your MCP stack and exposes a single endpoint to Claude Desktop. It routes tool calls to the right upstream server, filters what's in context, and keeps token counts under control.

## The Token Bloat Problem

Every MCP server you add to Claude Desktop injects its full tool schema into every conversation context. With 6 servers averaging 15 tools each, you're paying for 90 tool definitions on every message — even when you only need `read_file`.

FusionAL fixes this at the routing layer. Claude Desktop sees one server with one schema. The gateway handles routing, filtering, and upstream auth internally.
