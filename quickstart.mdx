## Step 1: Clone and install

```bash
git clone https://github.com/JRM-FusionAL/FusionAL.git
cd FusionAL

python -m venv venv
source venv/bin/activate        # macOS/Linux
# venv\Scripts\activate         # Windows

pip install -r core/requirements.txt
```

## Step 2: Start the gateway

```bash
cd core
python -m uvicorn main:app --reload --port 8009
```

Verify it's running:

```bash
curl http://localhost:8009/health
```

You should see a `200 OK` response.

## Step 3: Configure Claude Desktop

Find your config file:

| Platform | Path |
|----------|------|
| Windows | `C:\Users\YourName\AppData\Roaming\Claude\claude_desktop_config.json` |
| macOS | `~/Library/Application Support/Claude/claude_desktop_config.json` |
| Linux | `~/.config/Claude/claude_desktop_config.json` |

<Warning>
**Windows users:** Do not use `%APPDATA%` in the path. Claude Desktop does not expand environment variables. Hardcode the full path. Use forward slashes or double backslashes — single backslashes will silently break your config.
</Warning>

Quit and reopen Claude Desktop. Within a few seconds, FusionAL tools should appear in the tool picker. You'll see tools from all active upstream servers — BI, API hub, content automation, intelligence, and GitHub — all routed through the single gateway entry.
