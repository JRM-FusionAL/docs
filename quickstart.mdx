## Prerequisites

- Claude Desktop installed
- Access to `claude_desktop_config.json`
- FusionAL stack running (see [Self-hosting](/development) if you need to set that up first)

## Step 1 — Open your Claude Desktop config

<Tabs>
  <Tab title="Windows">
    ```
    C:\Users\<you>\AppData\Roaming\Claude\claude_desktop_config.json
    ```
  </Tab>
  <Tab title="macOS">
    ```
    ~/Library/Application Support/Claude/claude_desktop_config.json
    ```
  </Tab>
</Tabs>

## Step 2 — Add the FusionAL gateway

Replace any existing individual MCP server entries with a single FusionAL gateway entry:

```json
{
  "mcpServers": {
    "fusional": {
      "command": "npx",
      "args": [
        "-y",
        "@anthropic-ai/mcp-server-fetch",
        "http://gateway.fusional.dev/mcp/"
      ]
    }
  }
}
```

<Note>
  If you're connecting to a self-hosted instance over Tailscale, replace the domain with the Tailscale IP and port directly: `http://100.65.9.40:8009/mcp/`
</Note>

<Warning>
  Never use `localhost` in the config when Claude Desktop and the FusionAL stack run on different machines — `localhost` resolves to the client, not the server. Always use the Tailscale IP or public domain.
</Warning>

## Step 3 — Restart Claude Desktop

Quit and reopen Claude Desktop. Within a few seconds, FusionAL tools should appear in the tool picker. You'll see tools from all active upstream servers — BI, API hub, content automation, intelligence, and GitHub — all routed through the single gateway entry.

## Verify the connection

Ask Claude:

> "What FusionAL tools do you have available?"

Claude will list the active tools from all upstream MCP servers.
